# 🍗 Food Combo Puzzle

Part of my Python learning journey.

This project is based on a classic math problem, but I turned it into something more fun… FOOD 😄

---

## 💡 Problem

I want to buy exactly:

* **100 food items**
* With exactly **$100**

Menu:

* 🍗 Fried Chicken = $5
* 🍟 Fries = $3
* 🥤 Nuggets = $1/3

(yeah… nuggets are suspiciously cheap 💀)

---

## 🎯 Goal

Find all combinations of food that:

* Add up to **100 items**
* Cost exactly **$100**

---

## 🧠 Approach

Instead of solving it with equations, I used:

* Nested loops
* Conditions
* Brute-force search

The program tries all possible combinations until it finds the ones that work.

---

## ▶️ Example Output

```
🍗 Chicken:  4, 🍟 Fries: 18, 🥤 Nuggets: 78
🍗 Chicken:  8, 🍟 Fries: 11, 🥤 Nuggets: 81
🍗 Chicken: 12, 🍟 Fries:  4, 🥤 Nuggets: 84
```
