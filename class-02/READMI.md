# Class 2 - Python Learning Summary

In this class, I worked on several Python assignments focused on string manipulation and basic problem-solving.

## 📚 What I Learned

### 🔹 1. Working with Strings
- Taking user input using `input()`
- Accessing characters using indexing
- Reversing strings using slicing (`[::-1]`)

### 🔹 2. Loops and Iteration
- Using `for` loops to go through characters in a string
- Using `while` loops with conditions
- Understanding how to control loops with indexes

### 🔹 3. Conditional Statements
- Using `if` and `else` to make decisions
- Comparing values (e.g., checking if a string is a palindrome)

### 🔹 4. Dictionaries
- Creating and using dictionaries (`{}`)
- Counting frequency of characters in a string
- Updating values inside a dictionary

### 🔹 5. String Processing Techniques
- Splitting text into words using `.split()`
- Capitalizing words using `.capitalize()`
- Building new strings step by step

### 🔹 6. Problem Solving
- Checking for palindromes
- Counting characters
- Compressing strings (basic algorithm thinking)
- Formatting output cleanly

## 🚀 Key Takeaway
This class helped me improve my understanding of how to manipulate strings, use loops, and solve small problems step by step using Python.
